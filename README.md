# EVA URO CLUB - Conference Trip Management

## Description
A conference trip management system for EVA URO CLUB's trip to Prague.

## Features
- Login for members and admins.
- Admin dashboard for user management (create, list).
- Persisted user data on GitHub (users.json).
- Admin option to initialize demo users.

## Version History
- 1.0.001 - Initial implementation.
- 1.0.003 - Added password authentication and required password fields for users.
- 1.0.004 - Added demo user initialization functionality.
